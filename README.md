# 青笺 · AI Chat PWA

一个粉 / 白 / 灰配色、打开即聊天的 AI 角色聊天网站/PWA。视觉参考 iOS 的轻玻璃、圆角卡片和底部导航，但没有直接复制系统页面。

## 已实现

- 打开就是聊天界面，适配手机安全区与主屏幕安装。
- 用户人设 + 角色人设。
- OpenAI-compatible API：自定义 URL、Key、模型；支持拉取 `/models`、测试连接、`/chat/completions`。
- 预设：系统提示词、temperature、回复长度、历史轮数。
- 世界书：关键词命中后自动注入上下文。
- 正则：发送前 / 显示前替换。
- 表情包：本地批量导入，直接发送。
- 美化：强调色、背景色、气泡色、字号、聊天壁纸。
- 本地 JSON 导入 / 导出。
- PWA：manifest、Service Worker、离线缓存、系统通知权限。
- 工具：当前位置天气（Open-Meteo）、生成日历 `.ics`、网页提醒、打开 Apple Music 搜索。
- `server/` 提供最小 Web Push 服务端示例。

## 启动

不要直接双击 `index.html`，Service Worker 和部分权限需要 HTTPS 或 localhost。

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。

部署 GitHub Pages 后会自动使用 HTTPS，更适合 PWA。

## 关于“后台不被杀”和系统权限

纯网站做不到像 Android 原生前台服务那样保证常驻后台。浏览器/PWA 进程可能被系统暂停或清理。

- **关屏后仍收到通知**：需要 Web Push + 后端。Service Worker 可以被推送事件唤醒，不要求网页一直打开。
- **关屏后 AI 自动生成并主动发消息**：AI 调用必须迁移到后端，由后端保存角色配置、调度回复并通过 Web Push 发回手机。
- **系统闹钟**：网页不能可靠地直接创建手机系统闹钟。本项目提供网页提醒；真正的系统闹钟需要 Android/iOS 原生桥接。
- **日历**：网页可生成 `.ics` 交给系统日历导入；直接无感写入系统日历需要原生权限或第三方日历 API。
- **音乐**：网页可以打开音乐服务搜索/深链；直接控制其它音乐 App 取决于平台能力。

如果后续目标是“像真人聊天一样、稳定后台主动消息、直接调用系统能力”，建议用本项目 UI 和数据结构作为前端，进一步打包成 Capacitor/Android APK，再增加原生插件与推送服务。

## 安全

API Key 仅保存在当前浏览器 localStorage，仓库里没有真实密钥。公开部署时，更安全的方案是让前端只调用自己的后端代理，由后端读取环境变量中的 API Key。
